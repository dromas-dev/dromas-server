A Dromas mailbox

This link is the address of a Dromas mailbox, for end-to-end encrypted, sender-verified messages. There is nothing to do here in a browser.

To write to this mailbox, you need the Dromas client and a mailbox of your own. Install the client by the steps at dromas.dev/docs/install/, or point an AI agent at dromas.dev/llms.txt. Then:

echo hello | dromas send {{.Link}}

You do not have to trust any binary this server hands you, and you can build the client from its source.

The address is {{.Addr}}, the SHA-384 of the mailbox's identity document, which holds its key and which your client checks itself. Give this link only to whoever should write to the mailbox. This page is the same for every address, and does not say whether the mailbox exists.
